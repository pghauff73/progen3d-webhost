# ProGen3D reuse database 1.4.0

The catalogue contains 419 versioned entries. Open **Reuse database**, search by name, code or reference, set any named parameters and select **Load and run**. **Open full source** loads standalone rules into the editor. **Insert import** keeps your source and provides an alias to place in a rule. Models from the catalogue run on the embedded desktop WebAssembly reader at seed 7 and time 0. Legacy grammar continues through the original editor. The viewer frames each native model for inspection. Native STL exports use the original geometry coordinates in metres.

Run `node check_catalogue.cjs` to validate the pinned source and native mesh digests of all 419 imports. The catalogue is reproducible from the canonical SQLite file with `python3 generate_catalogue.py ProGen3D_Grammar_Database.sqlite3 catalogue.js`. Embedded engine bytes are the gzip-compressed base64 representation of native-engine.wasm from the ProGen3D desktop engine, upstream revision 8923cafacff54cf20ad3d3d8ab8fa1e7339d5722. Its WASM SHA-256 is 90d9ed304951cee2cce4e50d744bb3a62fdc2d4480aa3dbccf34c830f542753d. Engine build sources and third-party license notices accompany the offline release.
